# Mehrazin Malekghasemi — Personal Academic Website

An interactive academic portfolio built around **“Algorithms for a fairer world.”**

## Features
- Editorial / research-lab visual style
- Interactive research cards
- Orbit-style research map
- Academic journey timeline
- Dark/light mode
- Responsive layout
- No framework or build step
- GitHub Pages ready

## Profile
Mehrazin Malekghasemi is a Computer Engineering undergraduate at Sharif University of Technology, expected to graduate in February 2027. Her interests include theoretical computer science, algorithmic game theory, fair division, social choice, online algorithms, graph theory, and socially relevant algorithmic problems.

## GitHub Pages
The repository contains a static `index.html`, `style.css`, and `script.js`. Enable GitHub Pages from **Settings → Pages → Deploy from branch**, selecting the `main` branch and `/ (root)` folder.
